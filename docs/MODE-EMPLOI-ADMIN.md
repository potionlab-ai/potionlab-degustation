# Questionnaire de dégustation : mode d'emploi admin

**Adresse :** `https://degustation.potionlab.ai/admin` (email + mot de passe personnels)

## 1. Créer un questionnaire (5 min)
1. **Nouveau questionnaire**.
2. **Client et projet** : nom du client, nom du projet, **type de boisson**. Les questions de ce type s'ajoutent toutes seules (Bière : amertume, rondeur, houblon, finale…).
3. **Ce qui change** : une phrase courte par canette. *A : recette de référence · B : sucre −10 %…*
4. **Questions** : cochez ou décochez. L'appréciation globale (1 à 9) et le commentaire sont toujours posés.
5. **Sur mesure** (facultatif) : une question propre au client, par exemple « La note de framboise » en *Pas assez / Juste bien / Trop*.
6. **Créer et générer le code**.

👉 Pour une nouvelle itération ou un client proche : ouvrez un ancien questionnaire, puis **Dupliquer**.

## 2. Préparer la boîte
- Le code (ex. **K7P-M4X**) s'affiche en grand : **recopiez-le au stylo** sur la carte. Il ne contient jamais 0/O ni 1/I/L.
- Le client scanne le QR (le même sur toutes les boîtes), tape son code et arrive sur **son** questionnaire.
- Pour vérifier : **Voir comme le client**.

## 3. Suivre
**Tableau de bord** : taux de réponse, derniers retours et statut de chaque boîte : **Envoyé** → **Commencé** → **Terminé**.
Plusieurs personnes peuvent répondre avec le même code : leurs réponses sont additionnées.

## 4. Lire les résultats
- **Synthèse automatique** : la version préférée, puis pour chaque canette **✓ à garder** et **↓ réduire / ↑ augmenter**.
  *Règle : « à garder » si au moins 50 % des dégustateurs disent « juste bien ». Sinon, on suit la majorité.*
- **Piste pour la prochaine itération** : partir de la version préférée et reprendre ce qui est jugé juste ailleurs.
- **Barres** : 🔵 Pas assez · ⚪ Juste bien · 🟠 Trop, pour chaque critère et chaque canette.
- **Classement** : combien de fois chaque version a été classée 1re, et son rang moyen.
- **Commentaires** : par canette et généraux.

## 5. Partager et ranger
- **PDF** : rapport aux couleurs PotionLab, pour le client ou le patron. **CSV** : toutes les réponses, pour Excel.
- **Archiver** : le code ne fonctionne plus, les résultats restent consultables.
- Une réponse de test ? Liste **Dégustateurs** → 🗑.
- **Bibliothèque de questions** : modifier les questions proposées par défaut, en FR, EN, NL et ES. Les questionnaires déjà envoyés ne changent pas.
